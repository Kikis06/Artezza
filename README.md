# Artezza: catálogo digital

Sitio estático en HTML, CSS y JavaScript. No necesita instalación ni compilación.

## Ver el sitio

Abre la carpeta en VS Code, instala la extensión recomendada Live Server y elige **Go Live**.
También puedes abrir `index.html` directamente en el navegador.

## Antes de publicar

Todo se edita en `js/catalogo.js`:

1. Escribe el número en `CONFIG.whatsapp`. Sin él, el pedido no llega a la marca.
2. Reemplaza `PRODUCTOS` con las piezas reales y guarda las fotos en `img/productos/`.
3. Cambia `CONFIG.modoMuestra` a `false` para quitar el aviso de vista previa.
